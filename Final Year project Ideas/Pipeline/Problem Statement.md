Existing AI-based software pipeline transformation systems automate the conversion of software pipelines into standardized templates while aiming to preserve their original functionality. However, ensuring that the transformed pipeline behaves exactly like the original across all relevant execution conditions remains a verification challenge. Therefore, this project proposes a semantic verification system that compares original and transformed CI/CD pipelines, detects changes in execution logic, task dependencies, and conditional rules, and generates counterexamples to explain potential behavioral differences before deployment.
