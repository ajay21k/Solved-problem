### 🔹 What are Reserved Words?

Reserved words in Java are predefined words that have special meaning to the compiler.  
They **cannot be used as identifiers** (like variable names, class names, etc.).

👉 Total Reserved Words in Java = **53**

- **48 Used Keywords**
- **2 Unused Keywords**
- **3 Reserved Literals**

---

## 🔸 1. Java Keywords (48)

These are actively used in Java programming.

---

### 📌 Primitive Data Types

Used to define basic data types:

- `byte` – 8-bit integer
- `short` – 16-bit integer
- `int` – 32-bit integer
- `long` – 64-bit integer
- `float` – single precision decimal
- `double` – double precision decimal
- `boolean` – true/false
- `char` – single character

---

### 📌 Control Flow Statements

Used to control execution flow:

- Decision Making:  
    `if`, `else`, `switch`, `case`, `default`
- Looping:  
    `while`, `do`, `for`
- Jump Statements:  
    `break`, `continue`, `return`

---

### 📌 OOP (Object-Oriented Programming)

Used in class and interface design:

- `class` – defines a class
- `interface` – defines an interface
- `extends` – inheritance
- `implements` – interface implementation
- `import` – include packages

---

### 📌 Exception Handling

Used for handling runtime errors:

- `try` – block for risky code
- `catch` – handles exception
- `finally` – always executes
- `throw` – manually throw exception
- `throws` – declare exception
- `assert` – debugging check

---

### 📌 Object & Reference Keywords

Used for object creation and reference:

- `new` – create object
- `instanceof` – check object type
- `super` – refer parent class
- `this` – refer current object

---

### 📌 Method Return Type

- `void` – method returns nothing

---

### 📌 Access Modifiers

Define visibility:

- `public` – accessible everywhere
- `private` – accessible within class
- `protected` – accessible within package + subclass

---

### 📌 Non-Access Modifiers

Control behavior:

- `static` – belongs to class
- `final` – constant / cannot be overridden
- `abstract` – incomplete class/method
- `synchronized` – thread-safe
- `native` – method implemented in another language
- `strictfp` – controls floating-point precision
- `transient` – not serialized
- `volatile` – variable updated across threads

---

### 📌 Special Keyword

- `enum` – defines a fixed set of constants

---

## 🔸 2. Unused Keywords (2)

These are reserved but **not used in Java**:

- `goto`
- `const`

👉 Reserved for future use, but currently **not implemented**.

---

## 🔸 3. Reserved Literals (3)

These are constant values:

- `true` – boolean true
- `false` – boolean false
- `null` – no object reference

---

## 🧠 Key Points to Remember

- Reserved words **cannot be used as identifiers**
- Java is **case-sensitive**
- Keywords are always in **lowercase**
- `true`, `false`, `null` are **literals**, not keywords
