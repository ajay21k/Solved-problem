# 📚 System Design Obsidian Vault

A complete, interconnected Obsidian vault for mastering System Design — from fundamentals to real-world case studies.

## 🚀 Getting Started

1. **Download and install Obsidian**: https://obsidian.md (free)
2. **Open this vault**: File → Open Vault → Select this `SystemDesignVault` folder
3. **Start here**: Open `🗺️ MOC — System Design.md` — it's your home base
4. **Enable Graph View**: Click the graph icon in the left sidebar to see all notes connected

## 💡 Obsidian Tips

- **Graph View**: See all notes and their connections visually
- **Backlinks**: See which notes link to the current note (right sidebar)
- **Search**: `Cmd/Ctrl + Shift + F` to search across all notes
- **Quick Switcher**: `Cmd/Ctrl + O` to jump to any note
- **Tags**: Click any `#tag` or use the Tag Pane to filter notes
- **WikiLinks**: `[[Note Name]]` — click to navigate between notes
