### 💡 Idea

Since the array is **sorted**, duplicates are adjacent.  
Keep only **unique elements** by overwriting duplicates in-place.

---

### ⚙️ Approach

1. Use pointer `count` to track position of next unique element.
2. Start from index `1`:
    - If `nums[i] != nums[i-1]` → place at `nums[count]` and increment `count`.
3. Return `count` (length of unique elements).

---

### ✅ Code

class Solution {  
    public int removeDuplicates(int[] nums) {  
        int count = 1;  
  
        for (int i = 1; i < nums.length; i++) {  
            if (nums[i] != nums[i - 1]) {  
                nums[count] = nums[i];  
                count++;  
            }  
        }  
  
        return count;  
    }  
}

---

### ⏱ Time Complexity

- **O(n)** → Single pass through array

---

### 📦 Space Complexity

- **O(1)** → In-place (no extra space)

---

### 📝 Key Points

- Works only because array is **sorted**
- Uses **two-pointer technique (i, count)**
- Returns **new length**, not modified array
- First `count` elements are the final answer
